# 摸鱼小岛 · Moyu Island — Minecraft Server

A small private Minecraft server for friends. Java Edition and Bedrock play together.

## Server address

- Java Edition: `mc.jasonyong.de5.net` (no port needed, version 1.20.1)
- Bedrock Edition: `mc.jasonyong.de5.net`, port `19132` (Bedrock ~1.20.80)
- No password needed to join — just join and play.

## Website

https://jasonyong.de5.net — join guide, setup tutorials for Windows, Mac, Linux, Android and iPhone, FAQ, and video tutorials. The site opens in Simplified Chinese by default, with a language switcher for English, 日本語, 한국어 and Русский.

## Game modes

- Survival
- BedWars
- SkyWars
- Hide and Seek

In game, open the menu with `/menu`.

## Launchers and tools

Download links for HMCL, the official launcher, FCL (Android), Terracotta and EnchantNet are on the website.
