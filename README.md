- Java Edition: `mc.20261640.xyz` (no port needed, version 1.20.1)

http://20261640.xyz — join guide, setup tutorials for Windows, Mac, Linux, Android and iPhone, FAQ, and video tutorials. The site opens in Simplified Chinese by default, with a language switcher for English, 日本語, 한국어 and Русский.

- Survival
- BedWars
